# Myntra Clone – JavaScript

A functional **Myntra-inspired e-commerce website** built using **HTML, CSS, and JavaScript**. The project focuses on recreating the core shopping experience with dynamic product rendering, cart functionality, and persistent data using Local Storage.

## 🚀 Features

* 🛍️ Myntra-inspired e-commerce user interface
* 📦 Dynamic product listing using JavaScript
* 🛒 Add products to cart
* ➕ Increase/decrease product quantity
* 🗑️ Remove products from cart
* 💰 Dynamic cart price calculation
* 💾 Cart data persistence using **Local Storage**
* 🔄 Cart state remains available after page refresh
* 📱 Responsive and user-friendly interface
* 📄 Separate pages for different sections of the website

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Dynamic functionality and DOM manipulation
* **Local Storage** – Persistent cart data
* **Git & GitHub** – Version control

## 💾 Local Storage

The project uses the browser's **Local Storage API** to store cart-related data.

This allows the cart information to persist even after refreshing or reopening the page, providing a more realistic e-commerce experience without requiring a backend database.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ronit-0005/Myntra-clone-with-js.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

4. Start browsing products and adding items to the cart.

> No backend server or database setup is required.
